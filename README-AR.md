# كورهسطين — KORASTINE

نسخة المشروع المجمعة، مع تسجيل الدخول بـ **Google + الإيميل وكلمة السر**.

## الرفع مرة واحدة

ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (وليس ملف ZIP نفسه). اربط المستودع بـ Vercel، ثم أضف متغيرات البيئة الموضحة في `.env.example` في إعدادات Vercel. **لا ترفع المفاتيح السرية إلى GitHub.**

## إعداد Supabase (مطلوب لتفعيل الحسابات والتوقعات)

1. أنشئ مشروع Supabase وشغّل `supabase/schema.sql` في SQL Editor.
2. من Authentication → Providers فعّل Email وGoogle. يتطلب Google إنشاء OAuth Client في Google Cloud ووضع Client ID وClient Secret في إعدادات Google Provider في Supabase.
3. في إعدادات Google OAuth ضع **Callback URL الذي تعرضه Supabase** في Authorized redirect URIs؛ وفي Supabase → Authentication → URL Configuration أضف رابط موقعك `https://korastine.vercel.app` إلى Site URL وRedirect URLs.
4. اضبط `SUPABASE_URL` و`SUPABASE_ANON_KEY` و`SUPABASE_SERVICE_ROLE_KEY` في Vercel. مفتاح Service Role سري ولا يُكتب في الواجهة.
5. اضبط `API_FOOTBALL_KEY` لتشغيل المباريات. التغطية مقيدة بالخطة والمواسم المتاحة لدى مزود البيانات.
6. اضبط `CRON_SECRET` وشغّل طلب POST مؤمّن إلى `/api/settle` بصورة دورية بعد انتهاء المباريات لتسوية النقاط؛ لا توجد جدولة تلقائية مضمنة في هذا الإصدار.

## المميزات

- مباريات أمس واليوم وبكرة وتوقيت القاهرة.
- نتائج وشعارات وحالات المباريات عند توفرها لدى API-FOOTBALL.
- Google OAuth + تسجيل بالبريد وكلمة المرور واستعادة كلمة المرور.
- توقعات تُحفظ على السيرفر مع منع التوقع بعد بداية المباراة.
- XP افتراضية ولوحة متصدرين، وتسوية محمية بعد النتائج.
- صفحة مشاهدة لا تعرض بثًا دون تصريح.
- لوحة حالة خدمات للمشرف؛ إدارة المستخدمين التفصيلية من Supabase.

## ملاحظات مهمة

لا يمكن اعتبار تسجيل الدخول أو التوقعات شغالة فعليًا قبل إعداد Supabase وGoogle OAuth ومتغيرات Vercel، وتجربة الموقع بعد النشر. لا توجد جوائز نقدية أو بث مرخص مُضاف.

لتعيين مشرف، غيّر `role` إلى `admin` لمستخدم محدد من SQL Editor بعد التحقق من هويته.

## تحديث مصادر المباريات (Multi-source)
- `FOOTBALL_DATA_TOKEN`: مفتاح مجاني من football-data.org، يدعم هنا الدوري الإنجليزي والإسباني ودوري الأبطال ضمن التغطية المجانية. هذا المصدر قد يؤخر النتائج المباشرة؛ راجع شروط الخطة.
- `API_FOOTBALL_KEY`: اختياري للمباريات الإضافية إن كان لديك مفتاح وخطة تغطي البطولات. لا تحتاجه لتشغيل المصدر الأول.
- إذا لم يتوفر أي مفتاح، ستظهر قائمة فارغة بدل اختلاق نتائج. الدوري المصري والتركي والدوري الأوروبي ليست مضمونة عبر المصدر المجاني المفعّل.
- لم نفعّل OpenLigaDB تلقائيًا؛ لأن تغطيته الموثوقة لا تشمل كل بطولات كورهسطين، وإضافته دون مطابقة ثابتة للمباريات قد تفسد نقاط التوقعات.
- معرفات مباريات football-data.org مميزة بإضافة 1000000000 لتجنب التعارض مع المصدر الآخر. إذا تغير مصدر المباراة بين الزيارات، فقد يتغير معرفها؛ لذلك لا تعتمد على تسوية النقاط قبل اختبار ثبات المصدر والنتائج.
- المشروع يحتاج Supabase وإعداد OAuth على Vercel، ومهمة مجدولة مؤمنة لتسوية النقاط. لم يُختبر مع مفاتيح المستخدم الحقيقية.


## إعداد Supabase في Vercel (2026-11-23)
- `SUPABASE_URL` و `SUPABASE_PUBLISHABLE_KEY` موجودان بالفعل في مشروع Vercel.
- `/api/config` يدعم المفتاح الجديد `SUPABASE_PUBLISHABLE_KEY` مع توافق رجعي مع `SUPABASE_ANON_KEY`.
- لحفظ التوقعات يلزم `SUPABASE_SERVICE_ROLE_KEY` **على الخادم فقط**، بعد التأكد من إعدادات الأمان وSQL. لا تضف هذا المفتاح في كود المتصفح.
- عرض مباريات football-data.org متاح، لكن التوقعات مقصورة على مباريات api-football لأن الخادم يتحقق من معرف المباراة من المصدر نفسه.
- يجب إعادة النشر بعد تغيير متغيرات البيئة ورفع هذا الكود؛ لا تعتبر تسجيل الدخول أو التوقعات مختبرة حتى التجربة الحقيقية.
